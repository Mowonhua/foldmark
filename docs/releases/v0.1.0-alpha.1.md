# Foldmark v0.1.0-alpha.1

Foldmark 首个公开预发布版本，提供 Windows x64 安装包。

- 直接编辑本地 Markdown，支持待办、子任务、分区、已完成归档、源码视图和全文搜索。
- 支持代码高亮、公式、图片、主题导入导出及明暗切换。
- 自动保存文档，检测外部文件修改；冲突和保存失败时保留待处理内容，启动时可恢复草稿。
- 在「更多操作 → 检查更新」查看新版本，默认启动检查并自动下载；点击「安装并重启」前会保存全部文档和配置。后续预发布通过 preview 频道分发。

下载 `Foldmark_0.1.0-alpha.1_x64-setup.exe` 安装。缺少 WebView2 的设备首次安装需要联网下载运行时。应用文档保存在本地 Markdown 文件中。

此版本属于 alpha 预发布。更新签名用于应用内校验，安装包尚未配置 Windows Authenticode 证书签名。首次安装可能显示 Windows 未知发布者提示。
