# Foldmark v0.7.1

相较于 v0.7.0：

- GitHub 标签发布自动构建 Android arm64 签名 APK，与 Windows 安装包一起发布。任一平台缺少产物或校验失败时，不公开新版本。
- 手机支持检查、下载和安装新版本；安装前保存文档，由 Android 系统确认安装。
- 手机菜单、搜索和项目下拉支持点击外部关闭，侧栏支持左右滑动。

Windows 可在「更多操作 → 检查更新」升级，或下载 `Foldmark_0.7.1_x64-setup.exe` 安装。Android 可下载 `Foldmark-0.7.1-arm64.apk`，使用与已有版本一致的签名覆盖安装；后续版本可在应用内检查更新。

局域网同步需要电脑保持运行、手机处于前台，并连接同一局域网。
