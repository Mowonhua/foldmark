# Foldmark v0.1.0-alpha.2

本次预发布新增侧栏项目拖动排序，并修复段落、任务、代码和公式的编辑问题。

- 支持拖动调整左侧项目顺序。
- 修复段落编辑与空行显示问题，以及点击空任务正文时的光标定位。
- 统一代码块与公式块的编辑行为，修复代码语言选择浮层的布局。
- 调整更新界面，完善使用文档并添加 MIT 许可证。

可在「更多操作 → 检查更新」升级，或下载 `Foldmark_0.1.0-alpha.2_x64-setup.exe` 安装。缺少 WebView2 的设备首次安装需要联网下载运行时。

此版本属于 alpha 预发布，通过 preview 频道分发。安装包提供应用内更新签名，尚未配置 Windows Authenticode 证书签名，首次安装可能显示未知发布者提示。
