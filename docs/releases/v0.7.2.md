# Foldmark v0.7.2

相较于 v0.7.1：

- 局域网同步改为增量传输。协议升级至 3，只发送对端尚缺的文档版本，正文以行级补丁相对上一版本传输，无变化时仅交换标识，编辑后约 0.4 秒即开始同步。
- 同步失败或断开时按轮次退避重试，最长间隔 15 秒，恢复后自动回到增量传输。
- 桌面输入成对括号和引号时自动补齐闭符号，光标落在符号中间，支持跳过闭符号和一次删除整对。
- 手机端关闭弹窗不再唤起输入法；底部栏仅在配对后显示同步状态；设备同步面板与其他弹窗的样式和点击外部关闭行为一致。

Windows 可在「更多操作 → 检查更新」升级，或下载 `Foldmark_0.7.2_x64-setup.exe` 安装。Android 可下载 `Foldmark-0.7.2-arm64.apk` 覆盖安装。

局域网同步需要两端运行兼容版本，电脑保持运行、手机处于前台，并连接同一局域网。v0.7.2 使用的新同步协议与 v0.7.1 及更早版本不兼容，两端需一起升级。
