# Foldmark v0.4.0

相较于 v0.3.0：

- 新增灵感簿：侧栏一级入口托管项目外的独立 Markdown 文件，首次进入时在应用数据目录创建，支持重新定位与另存副本；任务、归档、折叠、排序、源码与公式照常，全局搜索覆盖灵感簿。
- 侧边栏新增大纲视图：按当前文档标题分区列目录，点击定位章节，滚动时实时高亮，可从大纲直接跳转其他项目或灵感簿。
- 正文字体改为系统字体点选：主字体、备用字体、兜底字体三个槽位可搜索、逐字体预览，保留手动输入字体栈并即时热切换。
- 「全部待办」按任务层级缩进显示父子关系并绘制章节干线；隐藏一级标题，按层级分级显示二级章节。
- 「全部待办」与拖拽预览跟随正文字体和字号，精简视图页头。
- 修复折叠摘要吞掉末行换行与紧随空行导致的异常高度，摘要行与正文行高等同。
- 修复在标题、引用、任务行等行末右侧空白点击时光标落到下一段开头的问题。

可在「更多操作 → 检查更新」升级，或下载 `Foldmark_0.4.0_x64-setup.exe` 安装。本版本通过 stable 和 preview 频道分发。
