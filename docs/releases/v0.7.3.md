# Taskrail v0.7.3

相较于 v0.7.2：

- 手机与电脑复用同一条已认证的 TLS 长连接传输变更通知、文档交换和心跳。两端编辑防抖四百毫秒后交换，电脑的修改主动通知手机，空闲每十五秒兜底交换一次，覆盖外部文件修改。
- 接收对端版本并成功保存后立即确认，不再等待下一轮交换，同步状态更快显示为「已同步」。
- 接收对端版本替换正文后保持阅读位置：视口顶部的原文行与像素偏移不变，末尾追加、上方插入和上方删除都不跳动。
- 手机检查更新和下载遇到连接中断时自动重建连接重试，并从已写入位置续传；服务端不支持续传或资源已变化时从头重下，重试仍失败时显示可重试的网络中断提示。
- 手机退到后台释放长连接，回到前台立即重连并交换；离线或连接失败时逐步延长重试间隔，最长十五秒。

Windows 可在「更多操作 → 检查更新」升级，或下载 `Taskrail_0.7.3_x64-setup.exe` 安装。Android 可下载 `Taskrail-0.7.3-arm64.apk` 覆盖安装。

局域网同步需要两端运行兼容版本，电脑保持运行、手机处于前台，并连接同一局域网。v0.7.3 的双向长连接与 v0.7.2 及更早版本不兼容，两端需一起升级。
