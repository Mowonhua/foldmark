# Foldmark v0.7.0

相较于 v0.6.0：

- 新增 Android 版，支持离线编辑、任务管理、归档、搜索和灵感簿。手机导入 Markdown 时创建私有副本，可通过系统文件选择器导出。
- 新增 Windows 与 Android 局域网同步。扫码并经电脑确认后，两端同步选定项目的正文、名称、归档状态及灵感簿。
- 同步使用共同版本合并独立修改；内容重叠或任务结构变化时保留双方版本，供用户合并。断线重连和重复传输不会静默覆盖本机修改。
- 手机编辑辅助栏使用图标按钮。修复底部留白输入、系统选字与复制粘贴、滚动条占位和通知拥挤换行问题。
- 同步复选框跟随正文主题，手机文档列表独立滚动，连接设置固定在页面底部。取消同步选择会撤回对端尚未接收的文档。
- 手机删除项目时清理私有 Markdown 文件和恢复草稿，保留导入来源及电脑文件。电脑移除项目关联时仍保留原文件。
- Windows 启动时恢复上次窗口位置。

Windows 可在「更多操作 → 检查更新」升级，或下载 `Foldmark_0.7.0_x64-setup.exe` 安装。Windows 更新通过 stable 和 preview 频道分发。Android 的签名构建和安装方式见[手机版与同步](https://github.com/Mowonhua/foldmark/blob/v0.7.0/docs/手机版与同步.md)。

同步需要两端运行兼容版本，电脑保持运行、手机处于前台，并连接同一局域网。本版本不提供云端同步或手机后台持续同步，不传输本地图片和附件。预览版的旧同步协议需要两端一起升级。
