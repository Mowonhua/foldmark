# Foldmark v0.1.0

Foldmark 首个正式版，支持直接在 Markdown 文件中编辑、整理和归档任务。

相较于 v0.1.0-alpha.2：

- 新增置顶卡片模式，方便在其他窗口旁查看和编辑任务。
- 新增液态玻璃、磨砂玻璃内置主题，并统一滚动条样式。
- 为侧栏与任务折叠添加过渡动画，优化折叠提示和展开图标。
- 修复窄窗口下的布局跳变与侧栏重叠，调整更新开关对齐和提示停留时间。
- 统一使用圆角折纸 F 应用图标。

可在「更多操作 → 检查更新」升级，或下载 `Foldmark_0.1.0_x64-setup.exe` 安装。本版本通过 stable 和 preview 频道分发。

缺少 WebView2 的设备首次安装需要联网下载运行时。安装包提供应用内更新签名，尚未配置 Windows Authenticode 证书签名，首次安装可能显示未知发布者提示。
