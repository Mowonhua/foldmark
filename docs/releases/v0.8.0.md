# Taskrail v0.8.0

相较于 v0.7.5：

- 新增 Markdown 画布：在待办正文中通过「更多操作 → 插入画布」或右键菜单插入内嵌白板，全页编辑文字、图形、连线、手绘和图片，编辑自动保存。
- 收起后的画布以内容预览为主，可随时展开继续编辑；设置新增「画布预览」，提供紧凑、适中、宽松三档（分别占正文两行、六行、十二行），仅影响本机阅读布局，不修改文档。
- 画布可导出 PNG；保存失败时保留编辑现场，可重试保存或导出图片。
- 画布图片保存在 Markdown 同目录的 `.assets/`，同目录文档按内容摘要共享图片；新增「导出完整文档」与「导入完整文档」，以 ZIP 连同图片搬运文档，普通 Markdown 导出不复制图片。
- 局域网同步支持画布图片附件，按分块传输，完整校验并保存后才应用正文；画布图片同步需要两端都运行 0.8.0。
- 应用标识、窗口标题、安装包与资源名称统一为 Taskrail，Windows、Android 和浏览器使用新的 T 字母双轨道图标。
- 设备同步的文档清单不再列出已归档项目，接收文档时的项目下拉也排除已归档项目；已在同步中的归档项目仍保留一行，可取消选择。
- 修复桌面输入法组合输入时中文成对符号不补齐。
- 修复玻璃主题最小化恢复时透出旧背景，消除最小化恢复瞬间的透明空档；欢迎页空状态标识改为 T。

0.8.0 更换了应用标识，不能从 0.7.5 原地覆盖升级。Windows 请下载 `Taskrail_0.8.0_x64-setup.exe` 安装，再重新关联原有 Markdown 项目；Android 请下载 `Taskrail-0.8.0-arm64.apk` 安装，新版会作为独立应用与原版并存。Markdown 原文件不受影响；旧版保存在应用数据目录中的界面配置与恢复草稿不会迁移。

局域网同步需要两端运行兼容版本，电脑保持运行、手机处于前台，并连接同一局域网。v0.8.0 沿用 v0.7.5 的同步协议，可与 v0.7.5、v0.7.4、v0.7.3 混用；含画布图片的文档需要两端都运行 0.8.0。与 v0.7.2 及更早版本不兼容，两端需一起升级。
