# Taskrail v0.8.1

相较于 v0.8.0：

- 手机端扫码改用 CameraX 配合 ML Kit 连续识别，整幅画面参与解码，取景框只作引导；原扫码页及其相机布局移除，光线一般时也能连续尝试识别配对二维码。
- 电脑端配对二维码按 1200px 生成、在同步面板中以 320px 呈现，点击可铺满窗口放大查看，点击任意处或按 Esc 只关闭放大层。
- 同步面板不再使用主题模糊底，固定定位的放大层不会因此被面板裁剪。
- 手机「更多操作」菜单移除完成整组、折叠当前项和同级上移下移入口，这些操作仍由列表项折叠按钮、完成提示和触屏辅助栏提供；菜单高度限制在顶栏以下的窗口剩余范围内滚动，条目再多也不越过窗口底边。

0.8.1 沿用 0.8.0 的应用标识，可从 v0.8.0 覆盖升级。Windows 下载 `Taskrail_0.8.1_x64-setup.exe` 安装，Android 下载 `Taskrail-0.8.1-arm64.apk` 安装。

局域网同步沿用 v0.8.0 的协议，可与 v0.8.0、v0.7.5、v0.7.4、v0.7.3 混用；含画布图片的文档仍需要两端都运行 0.8.0 或更新版本。与 v0.7.2 及更早版本不兼容，两端需一起升级。
