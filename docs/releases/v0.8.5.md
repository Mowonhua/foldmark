# Taskrail v0.8.5

相较于 v0.8.4：

- 修复中文输入法提交括号后页面按键失灵：组合输入期间不再改写正文，输入法提交结束后才补齐闭符号，提交的重复闭符号就近跳过；组合态正常结束，回车等按键立即生效。
- 修复在段内换行（Shift+Enter 续行）处新建任务后多渲染一行：新任务落在续行内时先断行，父段落与新任务各成一段，后续段落编辑不再把分隔空行读成续行。
- 状态栏字数统计不再计入画布快照：画布收起后的预览与源码视图统计一致，写作字数只按正文计算。

0.8.5 沿用 0.8.4 的应用标识，可覆盖升级。Windows 下载 `Taskrail_0.8.5_x64-setup.exe` 安装，Android 下载 `Taskrail-0.8.5-arm64.apk` 安装。

局域网同步协议未变，兼容范围与 v0.8.4 相同。含画布图片的文档需要两端都运行 0.8.0 或更新版本。与 v0.7.2 及更早版本不兼容，两端需一起升级。
