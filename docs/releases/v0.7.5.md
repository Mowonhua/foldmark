# Foldmark v0.7.5

相较于 v0.7.4：

- 接收对端版本时按差异分段呈现：阅读位置及其上方的删除与替换一次落定，下方改动逐段出现，视口顶部的行与像素偏移保持不变。
- 单行插入按字符块逐段显现，短句逐字、长句均分为固定块数，整段约 160 毫秒，节奏不再随屏幕刷新率变化；多行插入按行组依次出现。到达的行以柔和底色淡出标注，减少动效偏好下整段写入并跳过动画。
- 分段呈现期间开始编辑时，剩余差异立即落定；会话正文按最终文本记录后再做归档整理，中间状态不进入撤销历史。
- 同步合并界面改为逐处差异卡片：每处并列显示本机与对端内容，可选择保留本机、保留对端或同时保留两端，合并结果可继续编辑；无法自动取舍的改动不预填，选择完成前不能保存。
- 两端合并改为并集：双方各自新增的内容都保留，任务归档与排序等结构变化不再构成冲突，只有两端改动同一段已有内容时才需要选择。
- 手机端输入单个开符号时补齐对应的全角括号与中文引号，引号在汉字之后同样补齐，英文单词内的撇号不受影响；光标停在成对符号中间，退格一次删除整对，成对高亮只保留底色。
- 手机端切换项目、关闭菜单与搜索等浮层后不再自动唤起输入法，点按正文空白也不会弹出输入法；在一对符号内部再输入开符号时补齐内层符号。

Windows 可在「更多操作 → 检查更新」升级，或下载 `Foldmark_0.7.5_x64-setup.exe` 安装。Android 可下载 `Foldmark-0.7.5-arm64.apk` 覆盖安装。

局域网同步需要两端运行兼容版本，电脑保持运行、手机处于前台，并连接同一局域网。v0.7.5 沿用 v0.7.4 的同步协议，可与 v0.7.4、v0.7.3 混用；与 v0.7.2 及更早版本不兼容，两端需一起升级。
