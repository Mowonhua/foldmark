# Foldmark v0.3.0

相较于 v0.2.0：

- 新增正文右键菜单，支持文本格式、段落与列表转换、插入链接及代码块等 Markdown 编辑操作，并支持键盘导航。
- 完成子任务后保留在原父项下，统一收起为“已完成 xx 项”；整组完成后归档，保留二级及以下标题层级，恢复时回到对应章节。
- 统一任务折叠摘要与已完成子任务组的交互，保存完成组展开状态，搜索定位时自动展开目标。
- 新增玻璃主题窗口失焦时保持透明的设置，精简外观设置页，并统一正文与任务右键菜单的主题样式。
- 修复重复启动行为，同一程序路径复用已有实例，不同程序路径可独立运行。
- 修复“全部待办”中项目名与标题重复显示。

可在「更多操作 → 检查更新」升级，或下载 `Foldmark_0.3.0_x64-setup.exe` 安装。本版本通过 stable 和 preview 频道分发。

首次打开已有文件时会整理完成子项与归档布局并自动保存；历史归档中已丢失的原标题无法补回。
