# Taskrail v0.7.4

相较于 v0.7.3：

- 接收对端版本时按字符级差异替换正文，不再整份重建编辑器状态，接收过程中的画面跳动消失，视口顶部的原文行及其像素偏移保持不变。
- 锚点行的位置校正与正文更新在同一事务内提交，不再绘制出校正生效前的中间帧。
- 接收到的对端内容不进入撤销历史：本机原有编辑历史保留，对端版本仍不能整体回滚。
- 底部栏只提示需要处理的问题，即存在同步冲突、有文档待接收或同步失败；等待对端、等待确认、传输中和未打开对端时状态只留在同步面板，同步完成后也不再闪现「已同步」。

Windows 可在「更多操作 → 检查更新」升级，或下载 `Taskrail_0.7.4_x64-setup.exe` 安装。Android 可下载 `Taskrail-0.7.4-arm64.apk` 覆盖安装。

局域网同步需要两端运行兼容版本，电脑保持运行、手机处于前台，并连接同一局域网。v0.7.4 沿用 v0.7.3 的同步协议，可与 v0.7.3 混用；与 v0.7.2 及更早版本不兼容，两端需一起升级。
