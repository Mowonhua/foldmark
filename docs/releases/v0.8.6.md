# Taskrail v0.8.6

相较于 v0.8.5：

- 修复扫码返回后配对请求被推迟：本轮同步占用期间收到的配对或唤醒请求在结束后立即执行，不再等待最长十五秒的空闲退避。
- 修复 Windows 10 玻璃主题拖动窗口迟滞：系统早于 Windows 11 22H2 且没有背景材质属性时改用系统 Blur，保留透明模糊并消除拖动与缩放迟滞。
- 统一任务与画布的拖动落点：吸附范围内取最近落点，越过最低落点后仍追加到容器末尾；最后一段下方的大段空白继续作为末尾落点，画布可以拖到任务下方。
- 修复待办末尾空行的输入与光标错位：隐藏归档的行首与文末边界收敛到可见行，末尾空行与正文下方留白共用同一落点，点击不同位置的末尾留白结果一致。
- 修复滚动条出现导致主内容横向跳动：正文编辑区与待办列表预留固定滚动条槽位，文档或待办数量变化时正文宽度与居中位置保持不变。
- 统一空任务点击的视口定位：居中滚动改为可中断的平滑动画，点击空任务、空段落和底部留白时不再重复请求滚动。

0.8.6 沿用 0.8.5 的应用标识，可覆盖升级。Windows 下载 `Taskrail_0.8.6_x64-setup.exe` 安装，Android 下载 `Taskrail-0.8.6-arm64.apk` 安装。

局域网同步协议未变，兼容范围与 v0.8.5 相同。含画布图片的文档需要两端都运行 0.8.0 或更新版本。与 v0.7.2 及更早版本不兼容，两端需一起升级。
