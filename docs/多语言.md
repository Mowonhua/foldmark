# 界面语言

在设置的“语言”中选择 **简体中文**、**English** 或 **跟随系统**。选择立即生效并自动保存，重新打开应用时恢复。首次使用和未包含语言字段的旧配置默认使用简体中文。

“跟随系统”按系统首选语言列表匹配中文或英文；没有支持的语言时使用英文。运行期间收到系统语言变化事件后会自动更新。

语言设置只影响界面、提示、文件对话框及编辑器控件，不改写 Markdown 正文、项目名称、自定义主题名称或更新发布说明。切换语言保留光标、选区、折叠和撤销历史。已经出现的错误与临时通知保留发生时的文字，新操作使用当前语言。系统自身的原生对话框按钮和底层诊断采用系统提供的语言。

## 维护文案

统一入口为 `src/lib/i18n/index.ts`。Svelte 组件订阅 `t`，通过 `$t('中文原文', { name: value })` 使用当前翻译；普通 TypeScript 操作调用 `translate`，长期挂载的控件订阅 `locale` 更新显示。

英文词典按职责拆分为 `app-messages.ts`、`editor-messages.ts`、`platform-messages.ts` 和 `core-messages.ts`。中文原文是消息键，缺失英文译文时回退原文。动态文本使用完整句子和具名占位符，如 `{count}`，不要拼接翻译后的句子片段。参数只替换一次，文件名等用户输入不会被再次当成模板解析。

新增语言时，扩展 `Locale`、`LocalePreference` 和 `resolveLocale`，添加对应字典及设置选项，再补充语言解析、插值、切换和持久化测试。配置字段为 `preferences.locale`，值为 `zh-CN`、`en` 或 `system`；未知字符串回退中文，避免不同版本间的语言差异阻止读取其他配置。

验证命令：`npm run check`、`npm test`、`npm run test:app` 和 `npm run build`。编辑器语言用例覆盖即时刷新、后台项目恢复和撤销历史；应用用例覆盖设置选择、重新挂载与正文不变。
