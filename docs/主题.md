# 自制主题

设置中的“主题”选择一套配色，“明暗模式”选择浅色、深色或跟随系统。切换系统外观时，跟随系统会立即使用当前主题对应的配色。

内置“纸面”包含原有暖白纸面与炭灰配色。“纯粹”仅使用 `#0A0A0A` 和 `#F8FAFC`：浅色以 Slate 50 为背景，深色以 True Dark 为背景。选中态通过轮廓、文字样式与反色选区区分，关闭阴影和透明混色。正文中的图片仍显示原始内容；文字和边缘抗锯齿由浏览器渲染。

“新拟物”采用冷灰配色，提供浅色与深色外观。按钮以柔和双向阴影呈现凸起，输入框、当前导航项及任务复选框呈现内凹；归档复选框以 13px 蓝色实心块表示完成，完成态弱化外槽阴影，只保留细接缝。17px 外框使用 4px 圆角，内块按每侧 2px 的偏移使用 2px 圆角，使四角同心贴合。内块左上微亮、右下微暗，以表面受光区分填充与空槽；点击可恢复任务。正文和任务行保持平整，控件保留键盘焦点提示。

## 制作与导入

1. 在设置中选择一套接近目标的主题，点击“下载主题模板”。
2. 编辑 JSON 中的 `id`、`name` 和 `light`、`dark` 配色，可通过 `corners` 选择圆角或直角，通过 `appearance` 定义通用视觉参数。
3. 点击“导入主题”选择 JSON 文件。成功后自动应用，随应用配置保存，重启仍可使用。

桌面应用会打开系统保存对话框，选择位置后保存 `.json` 文件；浏览器预览使用浏览器下载。桌面保存失败会在设置中显示原因；若目标文件已存在，请另选文件名。

文件上限为 64 KiB，编码为 UTF-8。每份文件只包含一套主题。重复 ID 不会覆盖已有主题；可改用新 ID，或先移除已导入的同 ID 主题再重新导入。移除当前自定义主题会切回“纸面”。移除操作只删除应用内副本，不修改原 JSON 文件。

## JSON 字段

| 字段 | 约束 |
| --- | --- |
| `version` | 固定为数字 `1` |
| `id` | 1–64 个字符，以小写字母开头，其余允许小写字母、数字和连字符；导入时不能与已有主题（包括内置主题）重复 |
| `name` | 1–80 个字符，不得为空白 |
| `monochrome` | 可选布尔值；为 `true` 时，两套配色合计必须恰有两种颜色，并禁用透明混色效果 |
| `corners` | 可选，`rounded` 为圆角（缺省），`square` 为统一直角；独立于双色模式 |
| `appearance` | 可选对象；提供时必须同时包含 `light`、`dark` 两个视觉参数对象，各参数均可省略；`monochrome: true` 时不应用此扩展 |
| `light` / `dark` | 必须同时提供，且包含下表全部颜色键 |

颜色只接受 `#RRGGBB`，不接受透明色、CSS 表达式或资源 URL。未知附加字段在导入时忽略。

| 颜色键 | 用途 |
| --- | --- |
| `canvas` | 正文与页面背景 |
| `sidebar` | 侧栏背景 |
| `surface` | 弹窗、输入框和菜单背景 |
| `ink` | 正文前景 |
| `muted` | 次要文字 |
| `line` | 分隔线与边框 |
| `accent` | 强调文字、链接与选中控件 |
| `accent-soft` | 当前导航项与标签背景 |
| `hover` | 悬停背景 |
| `danger` | 错误与异常提示 |
| `code` | 代码区域背景 |
| `selection` | 选区背景 |
| `selection-ink` | 选区文字 |

制作双色主题时，让 `hover`、`accent-soft`、`code` 与 `canvas` 一致；将 `selection` 设为正文前景色，将 `selection-ink` 设为背景色。确保文字与其背景有足够对比度。

## 通用视觉参数

`appearance.light` 与 `appearance.dark` 分别描述两种模式的视觉参数。应用只消费固定的语义变量，不按主题名称、ID 或风格选择样式。新增主题使用同一套参数；修改主题配色时，需要同步调整视觉参数中的实色。

| 参数 | 用途 |
| --- | --- |
| `control-shadow` / `control-pressed-shadow` | 工具栏与表单按钮的常态、按下阴影 |
| `field-shadow` | 表单输入框与搜索框阴影 |
| `nav-active-shadow` | 当前导航项阴影 |
| `tabs-shadow` / `tab-active-shadow` | 标签组与选中标签阴影 |
| `floating-shadow` | 弹窗、菜单和搜索面板阴影 |
| `task-checkbox-shadow` / `task-checkbox-border` | 编辑器任务复选框与“全部待办”任务标记的阴影、边框；不影响表单原生复选框 |
| `task-checkbox-checked-shadow` | 已完成任务复选框外槽的阴影，缺省沿用 `task-checkbox-shadow` |
| `task-checkbox-checked-background` / `task-checkbox-checked-color` | 已完成任务复选框的背景与完成标记颜色 |
| `task-checkbox-checked-mark` / `task-checkbox-checked-mark-size` | 完成字符及字号；接受 `✓`、`●` 或空字符串，空字符串用于绘制几何标记；缺省使用 12px 对钩 |
| `task-checkbox-checked-mark-width` / `task-checkbox-checked-mark-height` / `task-checkbox-checked-mark-radius` | 完成标记的宽度、高度和圆角；缺省随字符自动排版、无圆角 |
| `task-checkbox-checked-mark-background` / `task-checkbox-checked-mark-shadow` | 完成标记的背景和阴影；缺省透明、无阴影，与复选框外槽独立 |
| `control-radius` / `field-radius` / `nav-radius` | 按钮、输入框和导航项圆角 |
| `tabs-radius` / `tab-radius` / `floating-radius` | 标签组、标签和浮层圆角 |
| `tabs-padding` / `tabs-gap` | 标签组内边距与标签间距 |
| `tab-active-weight` | 选中标签的字重 |
| `control-background` / `control-border` | 普通按钮背景与表单操作按钮边框；主操作按钮继续使用强调色 |
| `field-border` | 表单输入框与搜索框的常态边框 |
| `nav-active-background` / `tabs-background` / `tab-active-background` | 当前导航项、标签组与选中标签背景 |
| `divider-color` / `floating-border` | 应用分隔线与浮层边框 |

尺寸使用 `0`–`32` 的有限数字，单位为像素；字重为 `100`–`900` 的整数。颜色仅接受 `#RRGGBB` 或 `transparent`。阴影接受 `none` 或逗号分隔的最多四层，每层格式为 `[inset ]横向偏移px 纵向偏移px 模糊半径px #RRGGBB`；偏移为 −99 至 99 的整数，模糊半径为 0 至 99 的整数。不接受变量、函数、选择器、URL 或其他 CSS 表达式。未知参数忽略，非法的已知参数会使主题校验失败。

例如，在主题 JSON 顶层添加：

```json
"appearance": {
  "light": {
    "control-radius": 9,
    "control-shadow": "4px 4px 9px #c1c5c9, -4px -4px 9px #f6f8fa",
    "field-shadow": "inset 3px 3px 6px #c1c5c9, inset -3px -3px 6px #f6f8fa"
  },
  "dark": {
    "control-radius": 9,
    "control-shadow": "4px 4px 9px #1b1f25, -4px -4px 9px #363b45"
  }
}
```

缺省参数回退组件原有外观，切换主题或明暗模式时不会沿用上一次的参数。`corners: "square"` 优先保持直角；`monochrome: true` 优先保持双色。键盘焦点始终使用强调色，不受常态边框参数影响。导入、导出和配置保存均保留这些参数。

## 内置主题包

内置主题与第三方主题使用相同的 JSON 格式和结构校验：

- [纸面](../themes/paper.json)：浅深配色与圆角声明。
- [纯粹](../themes/mono.json)：浅深双色配色、双色效果和直角声明。
- [新拟物](../themes/neumorphic.json)：浅深冷灰配色、圆角和新拟物表面效果。

这些文件随应用构建打包，由 `src/lib/themes.ts` 登记加载；修改主题内容后需要重新构建应用。主题名称、颜色、边角及表面效果均以包文件为准，CSS 仅实现通用的配色与效果规则。复制任一包并改为唯一的 `id` 后即可通过设置导入，导出模板也会保留这些字段。
