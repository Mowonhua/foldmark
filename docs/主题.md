# 自制主题

设置中的“主题”选择一套配色，“明暗模式”选择浅色、深色或跟随系统。切换系统外观时，跟随系统会立即使用当前主题对应的配色。

内置“纸面”包含原有暖白纸面与炭灰配色。“纯粹”仅使用 `#0A0A0A` 和 `#F8FAFC`：浅色以 Slate 50 为背景，深色以 True Dark 为背景。选中态通过轮廓、文字样式与反色选区区分，关闭阴影和透明混色。正文中的图片仍显示原始内容；文字和边缘抗锯齿由浏览器渲染。

“新拟物”采用冷灰配色，提供浅色与深色外观。按钮以柔和双向阴影呈现凸起，输入框、当前导航项及任务复选框呈现内凹；归档复选框以 13px 蓝色实心块表示完成，完成态弱化外槽阴影，只保留细接缝。17px 外框使用 4px 圆角，内块按每侧 2px 的偏移使用 2px 圆角，使四角同心贴合。内块左上微亮、右下微暗，以表面受光区分填充与空槽；点击可恢复任务。正文和任务行保持平整，控件保留键盘焦点提示。

“液态玻璃”与“磨砂玻璃”都使用 Windows Acrylic 原生材质，柔化窗口后方内容。窗口底色完全透明，不额外叠加整窗颜色或装饰光斑。浅深模式的侧栏与浮层均按参考设置：磨砂玻璃使用约 8% 白色（`#FFFFFF14`）；液态玻璃不叠加实色底，使用 135° 白色反光渐变，在 0%／40%／100% 位置分别为约 22%／4%／12%（`#FFFFFF38`／`#FFFFFF0A`／`#FFFFFF1F`），顶部反光与边缘阴影独立叠加。

液态玻璃采用冷蓝配色，通过表面反光渐变、方向亮边、多层内阴影、有机圆角和胶囊按钮表现厚度与光泽；这些效果是视觉模拟。磨砂玻璃采用中性雾白与石墨配色，表面均质、细边低光。两者将参考样式适配到编辑器阅读与操作，不引入整块面板缩放、形变或漂浮光斑。侧栏与浮层的 CSS 模糊分别使用 8px／20px；磨砂表面饱和度为 1.6。这些参数只处理窗口内表面背后的图像，不能控制系统 Acrylic 的模糊半径。

普通主题恢复实色并移除原生效果。浏览器预览或不支持目标材质的平台使用实色窗口背景；窗口内表面效果按浏览器能力呈现。原生材质的明暗与设置中的明暗模式同步；选择“跟随系统”会解除原生窗口的显式明暗覆盖，避免浅色界面沿用深色 Acrylic 染色。原生效果取决于系统支持与透明效果设置。

## 制作与导入

1. 在设置中选择一套接近目标的主题，点击“下载主题模板”。
2. 编辑 JSON 中的 `id`、`name` 和 `light`、`dark` 配色，可通过 `corners` 选择圆角或直角，通过 `appearance` 定义通用视觉参数。
3. 点击“导入主题”选择 JSON 文件。成功后自动应用，随应用配置保存，重启仍可使用。

桌面应用会打开系统保存对话框，选择位置后保存 `.json` 文件；浏览器预览使用浏览器下载。桌面保存失败会在设置中显示原因；若目标文件已存在，请另选文件名。

文件上限为 64 KiB，编码为 UTF-8。每份文件只包含一套主题。重复 ID 不会覆盖已有主题；可改用新 ID，或先移除已导入的同 ID 主题再重新导入。移除当前自定义主题会切回“纸面”。移除操作只删除应用内副本，不修改原 JSON 文件。

## JSON 字段

| 字段 | 约束 |
| --- | --- |
| `version` | 固定为数字 `1` |
| `id` | 1–64 个字符，以小写字母开头，其余允许小写字母、数字和连字符；导入时不能与已有主题（包括内置主题）重复 |
| `name` | 1–80 个字符，不得为空白 |
| `monochrome` | 可选布尔值；为 `true` 时，两套配色合计必须恰有两种颜色，并禁用透明混色效果 |
| `corners` | 可选，`rounded` 为圆角（缺省），`square` 为统一直角；独立于双色模式 |
| `appearance` | 可选对象；提供时必须同时包含 `light`、`dark` 两个视觉参数对象，各参数均可省略；`monochrome: true` 时不应用此扩展 |
| `light` / `dark` | 必须同时提供，且包含下表全部颜色键 |

颜色只接受 `#RRGGBB`，不接受透明色、CSS 表达式或资源 URL。未知附加字段在导入时忽略。

| 颜色键 | 用途 |
| --- | --- |
| `canvas` | 正文与页面背景 |
| `sidebar` | 侧栏背景 |
| `surface` | 弹窗、输入框和菜单背景 |
| `ink` | 正文前景 |
| `muted` | 次要文字 |
| `line` | 分隔线与边框 |
| `accent` | 强调文字、链接与选中控件 |
| `accent-soft` | 当前导航项与标签背景 |
| `hover` | 悬停背景 |
| `danger` | 错误与异常提示 |
| `code` | 代码区域背景 |
| `selection` | 选区背景 |
| `selection-ink` | 选区文字 |

制作双色主题时，让 `hover`、`accent-soft`、`code` 与 `canvas` 一致；将 `selection` 设为正文前景色，将 `selection-ink` 设为背景色。确保文字与其背景有足够对比度。

## 通用视觉参数

`appearance.light` 与 `appearance.dark` 分别描述两种模式的视觉参数。应用只消费固定的语义变量，不按主题名称、ID 或风格选择样式。新增主题使用同一套参数；修改主题配色时，需要同步调整视觉参数中的实色。

| 参数 | 用途 |
| --- | --- |
| `window-material` | 原生窗口材质：`opaque`（缺省）、`transparent`、`blur`、`acrylic`；不按主题身份分支，双色主题强制使用实色 |
| `window-background` | 原生材质成功后使用的窗口底色，可带透明度；缺省回退 `canvas` |
| `backdrop-blur` | 页内模态弹窗打开时页面自身的模糊半径，0–64px，缺省为 0；通过页面 `filter` 生效，弹窗位于独立兄弟层，不依赖透明窗口的背景采样；两种玻璃主题均为 16px |
| `field-background` / `backdrop-background` | 文本输入框、选择框与对话框遮罩颜色；缺省沿用原配色，复选框和滑块不参与 |
| `sidebar-background` / `floating-background` | 侧栏及弹窗、菜单、搜索面板的表面颜色；缺省沿用基础配色 |
| `sidebar-blur` / `floating-blur` | 窗口内对应表面的 CSS 背景模糊半径；缺省为 0，不设置原生材质的模糊半径 |
| `surface-sheen-start` / `surface-sheen-middle` / `surface-sheen-end` | 侧栏与浮层的反光颜色，以 135°、0%／40%／100% 色标合成表面渐变；缺省透明，不用于窗口底图 |
| `surface-reflection` | 侧栏与浮层顶部椭圆反光的颜色，向外渐隐；缺省透明，绘制在文字下方 |
| `surface-saturation` / `surface-contrast` / `surface-brightness` | 侧栏与浮层背景的饱和度、对比度、亮度倍率；缺省均为 1，不改变前景文字 |
| `sidebar-shadow` / `workspace-shadow` | 侧栏与应用外壳的阴影；缺省无阴影，内置玻璃主题用内阴影描绘表面和窗口内沿 |
| `control-shadow` / `control-pressed-shadow` | 工具栏与表单按钮的常态、按下阴影 |
| `field-shadow` | 表单输入框与搜索框阴影 |
| `nav-active-shadow` | 当前导航项阴影 |
| `tabs-shadow` / `tab-active-shadow` | 标签组与选中标签阴影 |
| `floating-shadow` | 弹窗、菜单和搜索面板阴影 |
| `floating-border-top` / `floating-border-right` / `floating-border-bottom` / `floating-border-left` | 浮层四边颜色，分别回退 `floating-border`，再回退基础 `line` |
| `floating-radius-top-left` / `floating-radius-top-right` / `floating-radius-bottom-right` / `floating-radius-bottom-left` | 浮层四角圆角，分别回退 `floating-radius`，再回退对应组件原有圆角 |
| `task-checkbox-shadow` / `task-checkbox-border` | 编辑器任务复选框与“全部待办”任务标记的阴影、边框；不影响表单原生复选框 |
| `task-checkbox-checked-shadow` | 已完成任务复选框外槽的阴影，缺省沿用 `task-checkbox-shadow` |
| `task-checkbox-checked-background` / `task-checkbox-checked-color` | 已完成任务复选框的背景与完成标记颜色 |
| `task-checkbox-checked-mark` / `task-checkbox-checked-mark-size` | 完成字符及字号；接受 `✓`、`●` 或空字符串，空字符串用于绘制几何标记；缺省使用 12px 对钩 |
| `task-checkbox-checked-mark-width` / `task-checkbox-checked-mark-height` / `task-checkbox-checked-mark-radius` | 完成标记的宽度、高度和圆角；缺省随字符自动排版、无圆角 |
| `task-checkbox-checked-mark-background` / `task-checkbox-checked-mark-shadow` | 完成标记的背景和阴影；缺省透明、无阴影，与复选框外槽独立 |
| `control-radius` / `field-radius` / `nav-radius` | 按钮、输入框和导航项圆角 |
| `tabs-radius` / `tab-radius` / `floating-radius` | 标签组、标签和浮层圆角 |
| `tabs-padding` / `tabs-gap` | 标签组内边距与标签间距 |
| `tab-active-weight` | 选中标签的字重 |
| `control-background` / `control-border` | 普通按钮背景与表单操作按钮边框；主操作按钮继续使用强调色 |
| `control-sheen-start` / `control-sheen-end` | 普通工具栏及表单按钮、当前导航项与选中标签的 135° 表面反光；缺省透明，主操作按钮不使用此渐变 |
| `control-blur` | 普通工具栏及表单按钮的 CSS 背景模糊半径；缺省为 0，不影响原生窗口控制按钮 |
| `control-hover-background` / `control-hover-shadow` | 普通工具栏及表单按钮的悬停底色与阴影；缺省分别沿用 `hover` 和 `control-shadow` |
| `control-hover-lift` | 普通工具栏及表单按钮悬停时向上移动的像素数；缺省为 0，减少动态效果时不位移 |
| `field-border` | 表单输入框与搜索框的常态边框 |
| `nav-active-background` / `tabs-background` / `tab-active-background` | 当前导航项、标签组与选中标签背景 |
| `divider-color` / `floating-border` | 应用分隔线与浮层边框 |

尺寸使用 `0`–`32` 的有限数字，单位为像素；`backdrop-blur` 单独允许 `0`–`64` 像素；`control-hover-lift` 单独限制为 `0`–`2` 像素。三个 `surface` 滤镜倍率使用 `0.5`–`2` 的有限数字；字重为 `100`–`900` 的整数。视觉参数颜色仅接受 `#RRGGBB`、`#RRGGBBAA` 或 `transparent`；末尾 `AA` 为 alpha，`00` 完全透明、`FF` 完全不透明，基础配色仍仅接受六位实色。阴影接受 `none` 或逗号分隔的最多四层，每层格式为 `[inset ]横向偏移px 纵向偏移px 模糊半径px #RRGGBB`；偏移为 −99 至 99 的整数，模糊半径为 0 至 99 的整数。阴影颜色也支持 `#RRGGBBAA`。不接受变量、函数、选择器、URL 或其他 CSS 表达式；反光渐变由应用根据颜色参数生成。未知参数忽略，非法的已知参数会使主题校验失败。

例如，在主题 JSON 顶层添加：

```json
"appearance": {
  "light": {
    "control-radius": 9,
    "control-shadow": "4px 4px 9px #c1c5c9, -4px -4px 9px #f6f8fa",
    "field-shadow": "inset 3px 3px 6px #c1c5c9, inset -3px -3px 6px #f6f8fa"
  },
  "dark": {
    "control-radius": 9,
    "control-shadow": "4px 4px 9px #1b1f25, -4px -4px 9px #363b45"
  }
}
```

缺省参数回退组件原有外观。切换主题或明暗模式时清除上一套视觉参数，旧主题不会残留玻璃反光、滤镜、方向边缘或悬停位移。`corners: "square"` 优先保持直角，包括单独声明的浮层四角；`monochrome: true` 不应用视觉扩展，并恢复实色窗口、清除原生材质。键盘焦点始终使用强调色，不受常态边框参数影响。导入、导出和配置保存均保留这些参数。

表面反光不覆盖文字或拦截输入。悬停位移仅用于独立按钮，不移动正文、导航项、浮层或原生窗口控制按钮；按下时恢复原位。系统启用减少动态效果时，取消动画、过渡和悬停位移，颜色与焦点反馈仍保留。

## 内置主题包

内置主题与第三方主题使用相同的 JSON 格式和结构校验：

- [纸面](../themes/paper.json)：浅深配色与圆角声明。
- [纯粹](../themes/mono.json)：浅深双色配色、双色效果和直角声明。
- [新拟物](../themes/neumorphic.json)：浅深冷灰配色、圆角和新拟物表面效果。
- [液态玻璃](../themes/liquid-glass.json)：浅深冷蓝配色、表面反光、方向亮边、有机圆角和胶囊控件。
- [磨砂玻璃](../themes/frosted-glass.json)：浅深中性配色、均质雾面、细边和窗口内背景模糊。

这些文件随应用构建打包，由 `src/lib/themes.ts` 登记加载；修改主题内容后需要重新构建应用。主题名称、颜色、边角及表面效果均以包文件为准，CSS 仅实现通用的配色与效果规则。复制任一包并改为唯一的 `id` 后即可通过设置导入，导出模板也会保留这些字段。
