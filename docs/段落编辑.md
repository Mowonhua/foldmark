# 段落与空行

预览将段落之间的一行源码空行作为分隔隐藏。空段落本身仍有一个可编辑行，前后各使用一行分隔空行。加载时按源文解码；当前会话创建的空续行另外保留段内换行身份，与光标、选区、视口和焦点无关。

| 可见内容 | 源码表示（`\n` 表示换行） |
| --- | --- |
| A、B 两个段落 | `A\n\nB` |
| A、一个空段落、B | `A\n\n\n\nB` |
| A、两个空段落、B | `A\n\n\n\n\n\nB` |
| A、文末空段落 | `A\n\n` |
| 一个空段落 | 空字符串 |
| 段内软换行 | `A\nB` |

空段落不是 Markdown 语法树中的节点，因此编辑器需要从源码间隙补建它。加载既有文档时不改写源码；紧凑列表仍能直接显示，结构编辑只整理触及的段落及其两侧分隔。

## 编辑规则

- Enter、Ctrl+Enter 新建段落并补分隔；列表首行继续生成同级条目，空条目退出为一个空段落。
- Shift+Enter 只插入一个换行及必要的列表缩进，不添加反斜杠、HTML 标记或段落分隔空行。
- Backspace 在任务内容起点去掉标记，转换为正文段落，按列表容器保留正文缩进。
- Backspace、Delete 删除空段落时一并合并其两侧分隔；在兼容段落边界删除时合并正文。
- 删除段落中最后一个字形后保留空段落；再次删除才移除这个段落。
- 源码模式沿用原生文本输入规则。代码、引用、公式、表格等语法块的内部空白保持原意；隐式结构编辑不能将正文送入隐藏的折叠或归档范围。

## 实现边界

`paragraphs.ts` 从文档快照派生段落与分隔，并提供统一的局部段落替换计划。`preview.ts` 只消费模型中的分隔，导航原子范围与实际投影一致。`paragraph-editing.ts` 把键盘意图转换为段落操作，经同一序列化器提交一笔可撤销事务。

不得在预览中额外按光标位置展开空行，也不得在单个任务命令里独立计算空行配对或补分隔。

尚未输入文字的段内空续行由 `softBreaksField` 保存在编辑状态中，跟随文本修改映射，参与撤销重做，并在源码切换时保留。它不写入 Markdown；全文重新加载时，纯文本无法恢复空续行的编辑意图，按源文的段落分隔规则重新解码。空正文的缩进来自共享段落归属，与输入文字后的正文使用同一布局。
