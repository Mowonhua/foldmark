# 画布组件与字体许可

画布组件使用 `@excalidraw/excalidraw 0.18.1`。字体文件来自该版本的 `dist/prod/fonts`。`Liberation` 路径使用本项目的 Taskrail Sans 替代字体。

| 组件或字体 | 许可文件 | 上游来源 |
| --- | --- | --- |
| Excalidraw | [Excalidraw-MIT.txt](Excalidraw-MIT.txt) | [Excalidraw v0.18.1 LICENSE](https://github.com/excalidraw/excalidraw/blob/v0.18.1/LICENSE) |
| Assistant | [Assistant-OFL.txt](Assistant-OFL.txt) | [Google Fonts / Assistant](https://github.com/google/fonts/blob/main/ofl/assistant/OFL.txt) |
| Cascadia Code | [Cascadia-OFL.txt](Cascadia-OFL.txt) | [Microsoft Cascadia Code](https://github.com/microsoft/cascadia-code/blob/main/LICENSE) |
| Comic Shanns | [ComicShanns-MIT.txt](ComicShanns-MIT.txt) | [Excalidraw v0.18.1 字体元数据](https://github.com/excalidraw/excalidraw/blob/v0.18.1/packages/excalidraw/fonts/ComicShanns/index.ts) |
| Excalifont | [Excalifont-OFL.txt](Excalifont-OFL.txt) | [Excalidraw v0.18.1 字体元数据](https://github.com/excalidraw/excalidraw/blob/v0.18.1/packages/excalidraw/fonts/Excalifont/index.ts) |
| Taskrail Sans，基于 Liberation Sans 2.1.5 | [Liberation-OFL.txt](Liberation-OFL.txt) | [Liberation Fonts 2.1.5 LICENSE](https://github.com/liberationfonts/liberation-fonts/blob/2.1.5/LICENSE) |
| Lilita One | [Lilita-OFL.txt](Lilita-OFL.txt)、[Lilita-FONTLOG.txt](Lilita-FONTLOG.txt) | [Google Fonts / Lilita One](https://github.com/google/fonts/tree/main/ofl/lilitaone) |
| Nunito | [Nunito-OFL.txt](Nunito-OFL.txt) | [Nunito 项目](https://github.com/googlefonts/nunito/blob/main/OFL.txt) |
| Virgil | [Virgil-OFL.md](Virgil-OFL.md) | [Excalidraw Virgil](https://github.com/excalidraw/virgil/blob/main/LICENSE.md) |
| Xiaolai | [Xiaolai-OFL.txt](Xiaolai-OFL.txt) | [LXGW 小赖字体](https://github.com/lxgw/kose-font/blob/master/OFL.txt) |

许可文本保留上游原文。Comic Shanns 的 MIT 文本来自上游 `copyright` 字段。Excalifont 的 OFL 文本来自上游 `license` 字段，并保留对应的版权声明。这两个字段都包含完整授权文本。

[FONT-NOTICES.txt](FONT-NOTICES.txt) 保留实际分发字体的版权、字体版本、商标及内嵌许可字段。部分字体的内嵌版权年份与上游许可文件不同；两份声明都保留。

[sources.json](sources.json) 记录许可文件的下载地址、提取方式、字节数和 SHA-256。Taskrail Sans 的来源、改名及转换记录见 [字体说明](../../../third_party/canvas-fonts/README.md)。

安装包在 `canvas-assets/licenses/` 分发本目录的许可和声明文件。
